# Vaishali Saree — Frontend (Full Rebuild)

This is a complete rebuild of the whole project after the previous folder
only ended up with 4 files in it. Delete your old `vaishali-frontend` folder
entirely and use this one instead.

## Setup

```bash
npm install
npm run dev
```

Runs on http://localhost:5173 — make sure your backend (port 5000) is running too.

## Images

`public/main.png` (your hero banner) is already included.

You still need to copy these 4 files into `public/` yourself — I don't have
them, only you do (I saw them in your VS Code file explorer earlier):
- `silk.jpg`
- `cotton.jpg`
- `lenan.jpg`
- `bridal.jpg`

These are used in the category band below the hero on the homepage.

## What's included
Full MERN frontend: Home, Shop (filters/search/sort), Product Detail
(gallery, wishlist, reviews), Cart, Checkout (saved addresses, coupon code,
Razorpay/COD), Order Success, My Orders, Wishlist page, Account, Login,
Register (name, email, optional phone, password).
